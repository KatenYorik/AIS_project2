# Шаг 7. Панель Gradio

**Задание.** Отдельный процесс, подписанный на `/model_result` (через `rclpy` или общую
очередь). Показывает в реальном времени, **без ручного обновления**, текущий класс,
уверенность и, по желанию, последний кадр — через `gr.Label`, `gr.Image` и т. п.

## Что сделано — `gradio_panel.py`

Отдельный процесс. Узел `rclpy` работает в фоновом потоке, интерфейс перечитывает общее
состояние по таймеру `gr.Timer` раз в 0,3 с.

**Что показывает:**

- последний кадр входа (`gr.Image`);
- три вероятности (`gr.Label`);
- выбранное действие, класс сцены, уверенность решения, режим контроллера;
- **таблицу разложения `G`** на риск и неоднозначность по трём действиям — видно, почему
  выбрано именно это действие;
- счётчик кадров и задержку сети;
- **ленту состояний** за последние 150 решений: верхняя дорожка — класс сцены, нижняя —
  действие. Это тот же рисунок, что декодирование Витерби в научной части, только вживую.

**Два режима.**

| режим | откуда данные | зачем |
|---|---|---|
| `--mode ros` | подписка на `/image/compressed`, `/model_result`, `/action` | показывает то, что реально происходит в системе |
| `--mode local` | сама читает камеру или файл, выполняет ONNX и контроллер | когда ROS нет; демонстрация Проекта 1 с камеры |

| флаг | по умолчанию |
|---|---|
| `--model` | `best.onnx` (ищется от текущей папки, затем от `AIS\data\`) |
| `--source` | `0` — веб-камера; или путь к видео (от текущей папки) |
| `--classes` | `alert,empty,feeding` |
| `--controller` | `efe` или `threshold` (`--threshold 0.6`) |
| `--confusion` | `results\<запуск>.json` — матрица ошибок как `A` |
| `--fps`, `--imgsz`, `--port` | 5, 224, 7860 |

`efe.py` панель берёт из пакета через `common\aispaths.py`.

## Трудности

- **Пустая панель в WSL без видимой ошибки.** Gradio 6 при каждом событии импортирует
  matplotlib, а системный matplotlib 3.6 в Ubuntu 24.04 собран под NumPy 1.x и падал на
  NumPy 2.5. Решение — gradio и matplotlib 3.11 в `~/.local`
  (`pip install --user --break-system-packages`). **Не откатывать NumPy на 1.x**: на нём
  работают opencv 5 и onnxruntime.
- **Вкладка, открытая при лежащем сервере, застревает** в переподключении и не
  обновляется, даже когда сервер поднят. Лечится **новой** вкладкой.
- **Порт 7860 занят** прошлой панелью — новая не встаёт, а страница показывает старую.
  Погасить: `pkill -9 -f '[g]radio_panel'` (квадратные скобки — чтобы `pkill` не убил свою
  же оболочку).
- В режиме `local` панель сначала сплющивала кадр 16:9 в квадрат. Исправлено: центральная
  обрезка, как при обучении.

```powershell
cd C:\Users\kkhod\claude\AIS
python project2\step7_gradio_panel\gradio_panel.py --mode local --model runs\classify\pretrain_stage2\weights\best.onnx --confusion results\pretrain_stage2.json --source 0
```
