# Шаг 2. Модель

**Задание.** Любой фреймворк, экспортируемый в ONNX. Дообучение не обязательно, если
готовая модель решает задачу. Оценить подходящими метриками, описать выбор и обучение.
ClearML рекомендуется.

## Что использовано

**Итоговая модель Проекта 1** — `pretrain_stage2`:

- `yolo11n-cls`, 1,53 млн параметров;
- предобучение ImageNet → 1567 вырезок Visual WetlandBirds (13 видов, 10 эпох) →
  дообучение на 588 своих кадрах на три класса (30 эпох);
- веса: `data\runs\classify\pretrain_stage2\weights\best.pt` и `best.onnx`;
- метрики: `data\results\pretrain_stage2.json`; журнал — ClearML, проект `AIS-birds`.

Обучение, эксперименты и выбор — `project1\step4_baseline_model\`,
`project1\step6_experiments\`.

## Оценка

Проверка — 204 кадра четырёх клипов, не участвовавших в обучении.

| | accuracy | macro-F1 |
|---|---|---|
| константа «всегда `empty`» | 0.422 | 0.198 |
| **итоговая модель** | **0.510** | **0.402** |

Матрица ошибок (строки — истина, столбцы — ответ):

| | alert | empty | feeding |
|---|---|---|---|
| **alert** (61) | 52 | 9 | 0 |
| **empty** (86) | 28 | 52 | 6 |
| **feeding** (57) | 36 | 21 | **0** |

**Почему она.** Единственная из 13 моделей, обошедшая константу по обеим метрикам.

**Главный изъян** — последняя строка: кормление не распознаётся ни разу. Весь Проект 2
строится с этим изъяном на виду. Эта же матрица подаётся контроллеру как правдоподобие
наблюдения (параметр `confusion`) и определяет его поведение (шаг 6).
