# Шаг 3. Экспорт в ONNX и валидация

**Задание.** Экспорт средствами фреймворка; документировать имена и формы входа/выхода,
версию opset, динамические оси. Скрипт валидации: один и тот же вход через исходную
модель и `onnxruntime`, совпадение в пределах погрешности; задержка на своём железе.
**Артефакты:** `.onnx`, скрипт валидации, раздел отчёта.

## Что сделано — `export_onnx.py`

Одним запуском: экспорт → численная сверка → замер задержки.

**Экспорт** — `model.export(format="onnx", imgsz=224, opset=12)` из ultralytics.

| параметр | значение |
|---|---|
| файл | `data\runs\classify\pretrain_stage2\weights\best.onnx`, 6,1 МБ (рядом с `best.pt`) |
| opset | 12 |
| вход | `images`, `float32`, `[1, 3, 224, 224]`, RGB, значения 0…1 |
| выход | `output0`, `float32`, `[1, 3]` — **уже вероятности**, софтмакс внутри графа |
| порядок классов | `alert, empty, feeding` — алфавитный, так задаёт ultralytics |
| динамические оси | нет: батч 1, робот обрабатывает кадры по одному |

**Валидация.** 60 кадров проверочной выборки, по 20 на класс. Квадрат 224×224 готовится
**один раз** — масштаб по короткой стороне и центральная обрезка, как при обучении — и
подаётся обоим путям. Так сравнивается экспорт, а не препроцессинг.

| проверка | результат |
|---|---|
| максимальное расхождение вероятностей | **2.15·10⁻⁶** |
| кадров со сменой предсказанного класса | **0 из 60** |
| onnxruntime, CPU, медиана / 95-й перцентиль | **6,0 / 7,0 мс** (165 кадров/с) |
| PyTorch через ultralytics, медиана | 18,6 мс |

Процессор AMD Ryzen 5 5500U. Ускорение втрое — в основном потому, что убран питоновский
слой ultralytics вокруг сети, а не потому, что изменилась сеть.

Итог пишется в **`data\results\onnx_validation.json`**; вердикт `valid: true` ставится при
расхождении меньше 10⁻² и нуле смен класса.

## Ошибка, найденная при валидации

Первый прогон дал расхождение **0.42** при нуле смен класса — «невозможная» комбинация.
Причина была в самой проверке: она безусловно применяла `exp` к выходу, который уже был
вероятностями, и получался софтмакс поверх софтмакса. Порядок классов он сохраняет,
а числа сплющивает. Исправлено: софтмакс применяется, только если выход — не
распределение. Урок: при невозможной комбинации метрик сначала проверять инструмент.

## Как запускать

Из `C:\Users\kkhod\claude\AIS`, пути от `AIS\data\`:

```powershell
python project2\step3_onnx_export\export_onnx.py --weights runs\classify\pretrain_stage2\weights\best.pt --data datasets\birds_v1_course3
```

**Повторный запуск перезаписывает** `best.onnx` (тем же экспортом) и
`results\onnx_validation.json` — задержка при этом немного сдвинется, и числа в отчёте
придётся обновить.

| флаг | по умолчанию |
|---|---|
| `--per-class` | 20 кадров на класс для сверки |
| `--runs` | 50 прогонов для замера задержки |
| `--opset` | 12 |
